# Fundamentos de Programação em linguagem C

O repositório Fundamentos de Programação em C funciona como um diário de bordo online para centralizar e salvar meus estudos e arquivos locais na linguagem C.

O objetivo aqui não é criar os códigos mais perfeitos do mundo, mas sim documentar e acompanhar a minha evolução na programação procedural.

Organização dos meus estudos:

C e Python: Este repositório foca em C, e futuramente criarei um dedicado a Python.

<strong>JavaScript:</strong> Mantenho <strong>meus códigos de JS salvos no aplicativo Mimo, na Khan Academy e localmente no PC</strong>. 
<em>(Apesar de ter sido a minha primeira linguagem e de eu gostar muito — e com o Scratch ficando no esquecimento, porque ninguém liga, né? Mas eu sim)</em>. 
<br>
<strong>[AVISO]</strong> Caso volte a programar ativamente nessa linguagem, irei transferi-los para o GitHub. Por enquanto, o foco por aqui é este!
